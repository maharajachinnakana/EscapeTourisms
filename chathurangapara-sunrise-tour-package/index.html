How the fare works

The fare is for the vehicle, with a local driver, for the whole day. It does not change with the number of passengers.

The Jeep fare of ₹5,000 is the full package with the Chathurangapara safari included. For other vehicles the jeep safari is ₹1,200 and is booked separately.

02 / The route

What this package covers.

Chathurangapara sits on a ridge near the Kerala–Tamil Nadu border with wide valley views, and the sunrise jeep climb is the start of a long day. After sunrise you pass a waterfall you can bathe in, a spice garden and then the same tea-estate circuit as our Kolukkumalai package.

If you want zero extra charges for the jeep, choose the full Jeep package at ₹5,000. If you prefer a sedan or an Innova for comfort, the safari is added at ₹1,200.
